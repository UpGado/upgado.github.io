It's time. I have officially spent more than one year working a professioanl software engineer! I have learned a TON TON during my job. Like, soft stuff, hard stuff, code stuff, and cloud stuff. Before this job, I had only coded in hobby or academic settings, which are _so_ different from what a real world job as a software engineer demands. Here are my findings, just for you my dear reader:


### It's not just about code

You would think a software engineer's main job is to write code, but you're only 25% correct. In reality, writing code was the _easiest and least time-consuming_ part of my job. What actually took time and skill was the stuff that comes before writing code: thinking about the problem and designing a good solution at the macro-level. For example, if you are adding a new feature to some existing application, where in the application code do you add it? How are responsibility assigned to the different parts of the system such that this feature works? How do you ensure this feature is flexibile enough to accomodate future requirements? Is this feature going to break all the time, or did you design it well enough that it is robust?

These are all questions that have nothing to do with code, code readability, or your ability to figure out fast algorithms. I didn't learn this in class, but this is the stuff that sets apart the talented programmers from the game-changing ones.
